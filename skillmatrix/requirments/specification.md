Вот **полное техническое задание (ТЗ)** на реализацию первой версии системы управления скилл-матрицами, упрощённой под MVP.

---

## 📘 Техническое задание: Система управления скилл-матрицами (v1)

### 🎯 Цель

Разработать веб-приложение для **создания и управления скилл-матрицами** внутри одной организации. Продукт будет использоваться для описания требований по навыкам для различных направлений (например, Frontend Developer, Backend Developer и т.д.) без проведения оценок.

---

## 🧱 Основные возможности

### 1. Управление скилл-матрицами

* Создание, редактирование, удаление матриц.
* Структура: `Matrix → Category → Topic → Subtopic`.
* Публичность матрицы (флаг публикации).

### 2. Навыки и подтемы

* Создание и редактирование Subtopics.
* Привязка навыков (`Skills`) к Subtopics.
* Навыки могут быть повторно использованы в разных Subtopics.

### 3. Требования по грейдам

* Справочник фиксированных грейдов (J1–S3).
* Справочник уровней знаний: None, Novice, Intern, Advanced.
* Для каждой Subtopic можно задать требуемый уровень знания по каждому грейду.

### 4. Источники знаний (ресурсы)

* Добавление ссылок и материалов (документации, статей).
* Привязка ресурсов к навыкам.

## 🧩 Сущности и поля

### 🟦 `SkillMatrix`

| Поле         | Тип     | Описание              |
| ------------ | ------- | --------------------- |
| matrix_id    | UUID    | Идентификатор матрицы |
| title        | string  | Название матрицы      |
| description  | text    | Описание              |
| is_published | boolean | Флаг публикации       |

---

### 🟨 `Category`

| Поле        | Тип       | Описание                |
| ----------- | --------- | ----------------------- |
| category_id | UUID      | Идентификатор категории |
| matrix_id   | UUID (FK) | Ссылка на матрицу       |
| name        | string    | Название                |
| order_index | int       | Индекс сортировки       |

---

### 🟧 `Topic`

| Поле        | Тип       | Описание              |
| ----------- | --------- | --------------------- |
| topic_id    | UUID      | ID темы               |
| category_id | UUID (FK) | Принадлежит категории |
| name        | string    | Название              |
| order_index | int       | Индекс в категории    |

---

### 🟪 `Subtopic`

| Поле        | Тип       | Описание                  |
| ----------- | --------- | ------------------------- |
| subtopic_id | UUID      | ID подтемы                |
| topic_id    | UUID (FK) | Принадлежит теме          |
| name        | string    | Название                  |
| description | text      | Краткое описание/контекст |

---

### 🟥 `Skill`

| Поле        | Тип                           | Описание                                |
| ----------- | ----------------------------- | --------------------------------------- |
| skill_id    | UUID                          | ID навыка                               |
| description | text                          | Суть навыка / вопрос                    |
| type        | enum(theory, practical, soft) | Тип: теоретический, практический и т.п. |

---

### 🔄 `SubtopicSkill` (связь многие-ко-многим)

| subtopic_id | UUID (FK) |
| ----------- | --------- |
| skill_id    | UUID (FK) |

---

### 🟩 `Grade` (фиксированный справочник)

| grade_code | string | Пример: J1, M2 |
|------------|--------|
| name       | string |
| rank       | int    |

---

### 🟫 `KnowledgeLevel` (фиксированный справочник)

| level_code | int    | 0–3 |
|------------|--------|
| name       | string |
| description| string |

---

### 🔷 `Requirement`

| subtopic_id    | UUID (FK)   |
| -------------- | ----------- |
| grade_code     | string (FK) |
| required_level | int (FK)    |

---

### 🟨 `Resource`

| resource_id | UUID   |
| ----------- | ------ |
| title       | string |
| url         | string |

---

### 🔗 `SkillResource` (многие-ко-многим)

| skill_id     | UUID (FK)  |
| resource_id  | UUID (FK)  |
| note         | string     |

---

## ⚙️ Бизнес-правила

* Одна матрица содержит ≥0 категорий, категории — ≥0 тем, темы — ≥0 подтем.
* Навык может использоваться в разных подтемах.
* У каждой подтемы может быть 0 или более требований по грейдам.
* Уровень знания фиксируется из справочника KnowledgeLevel.
* Навыки могут иметь материалы (ресурсы) для изучения.
